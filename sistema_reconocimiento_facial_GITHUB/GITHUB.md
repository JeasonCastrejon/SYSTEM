# Publicar en GitHub

1. Crea un repositorio nuevo y vacío en GitHub.
2. Sube el contenido de esta carpeta (especialmente `frontend/` y `backend/`).
3. No subas `backend/venv`, `frontend/node_modules` ni archivos `.env`.
4. Los archivos `.env.example` sí están incluidos como plantillas.
5. Para ejecutar localmente, sigue las instrucciones del `README.md`.

El código de `frontend/` y `backend/` se conserva sin cambios; este paquete solo elimina dependencias/cachés generados y añade configuración de Git.
